# Monitor Brightness

Небольшая программа для Windows 11: значок в трее, выбор монитора, отдельные ползунки аппаратной яркости и контрастности через DDC/CI. Использует Windows PowerShell 5.1 и встроенный API dxva2.dll. Установка драйвера и права администратора не требуются.

**Подходит не только для ViewSonic:** программа обнаруживает подключённые к ПК внешние мониторы разных производителей и позволяет выбрать нужный в списке. Для аппаратного управления монитор и подключение должны поддерживать DDC/CI; включите эту функцию в экранном меню монитора. Доступность яркости и контрастности зависит от конкретной модели, режима изображения и подключения. Совместимость со всеми мониторами не гарантируется.

## Возможности

- Отдельное управление яркостью и контрастностью выбранного монитора.
- Работа с несколькими внешними мониторами, подключёнными к одному ПК.
- Значок монитора в системном трее и компактное окно с ползунками.
- Включение и отключение автозапуска при входе в Windows.
- Ограничение частоты команд DDC/CI и автоматическое восстановление после временных ошибок.
- Режим диагностики, который только читает параметры мониторов.

## Запуск

1. Включите DDC/CI в меню монитора.
2. Запустите `Diagnose-Brightness.cmd`. Диагностика только читает яркость и контрастность; `DDC/CI OK` означает, что монитор ответил. Запись проверяется отдельно при перемещении соответствующего ползунка. Если контрастность недоступна, её ползунок отключается независимо от яркости.
3. Запустите `Start-Brightness.cmd` и нажмите на значок приложения в трее (возможно, он находится в списке скрытых значков).
4. Выберите нужный монитор в списке и передвиньте ползунок. Изменение отправляется после отпускания мыши и паузы 700 мс. Между командами выдерживается интервал не менее 500 мс по времени начала запросов. Для проверки сравните значение с яркостью в экранном меню монитора.

Правой кнопкой по значку → Exit завершает программу. Refresh заново обнаруживает мониторы после сна или переподключения. Программа ничего не меняет при запуске. Выбор монитора и яркость не сохраняются в отдельный файл; сохранение значения самим монитором зависит от его прошивки.

Автозапуск при входе текущего пользователя в Windows включается и отключается через пункт **Start with Windows** в меню правой кнопки значка. Галочка означает наличие записи приложения в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`. Приложение запускается скрыто, без окна PowerShell; права администратора не требуются. Не перемещайте папку приложения, пока автозапуск включён. После перемещения отключите и снова включите этот пункт из нового расположения.

Значок приложения — синий монитор с жёлтым солнцем; подсказка при наведении: `Monitor Brightness - brightness and contrast`. При запуске значок рисуется встроенными средствами Windows. Файлы `MonitorBrightness.ico` и `MonitorBrightness.png` — сохранённые копии значка, они не нужны для работы.

Интерфейс пока на английском, чтобы исходный PowerShell-файл корректно читался Windows PowerShell независимо от кодировки системы. Обмен DDC/CI выполняется последовательно в фоновом потоке. После ошибки чтения или записи программа автоматически повторяет обнаружение через 15 секунд; при повторных ошибках пауза увеличивается до 30, 60 и максимум 120 секунд. Во время паузы команды записи и ручное обновление не отправляются. После успешного восстановления ползунки снова включаются. Выход во время активного запроса завершается после его возврата, чтобы не освобождать используемые дескрипторы мониторов.

## Если монитор не отвечает

Скопируйте результат из окна диагностики. Проверяйте при включённом мониторе; после сна нажмите Refresh. Успешное управление Dell не доказывает доступность DDC/CI у ViewSonic. Эта программа не обходит ограничения прошивки или видеодрайвера.

Если ошибка сохраняется даже после выхода из программы, выключите монитор, отключите его питание на 20–30 секунд и включите снова. Это может восстановить зависший контроллер DDC/CI. На время проверки закройте другие программы управления монитором, чтобы исключить одновременные запросы. Диагностику запускайте после выхода из программы, а не одновременно с ней.

## Статус проверки

Работа яркости и контрастности подтверждена на ViewSonic VX2780-2K. Из-за наблюдавшихся периодических сбоев DDC/CI добавлены ограничение частоты запросов, фоновый обмен и автоматическое восстановление после ошибок. Компиляция текущей версии проверена в Windows PowerShell 5.1; создание значка 32×32 и запись автозапуска проверены. Проверки настройки автозапуска и значка не отправляют команды монитору. На других моделях совместимость нужно проверить через диагностику и экранное меню.
